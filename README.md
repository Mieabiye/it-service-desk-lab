IT Service Desk Troubleshooting Lab

Project Overview

This repository demonstrates practical IT support and service desk troubleshooting through simulated incidents involving common Windows workstation, account access, network connectivity, and printer issues.

The purpose of this project is to practise structured troubleshooting, incident documentation, root-cause analysis, resolution verification, and escalation procedures relevant to entry-level IT support roles.

Objectives

- Document IT incidents in a structured and professional format.
- Identify possible causes of common technical problems.
- Develop a logical troubleshooting process.
- Record resolutions and verification steps.
- Practise incident prevention, escalation, and support documentation.

Troubleshooting Methodology

Each incident follows a structured workflow:

1. Record the problem and its impact.
2. Identify possible causes.
3. Investigate using appropriate diagnostic steps.
4. Identify the simulated root cause.
5. Document the resolution.
6. Verify the outcome.
7. Recommend preventive measures or escalation.
